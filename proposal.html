Why a New Training Format for JAN-9301

The current format served the JAN-9201 era well; the next model needs more

Current (JAN-901B / 9201)

  • Windows-only desktop apps with large installers (650–720 MB)
  • Account and install link sent to each trainee by e-mail
  • Records cover completion and test scores only
→

Required for JAN-9301

  • Any screen: web browser, PC and tablet
  • One-time install on first web access for offline use; account and install handled in the platform, no e-mail needed
  • More natural voice narration than the current course
  • Hands-on practice on a full-screen JAN-9301 replica (2D CBT), focused on ECDIS operation
  • Evidence of each practical skill, not just completion

Under Review: Cyber Security (IACS UR E26/E27)

Not part of the JRC ECDIS type-specific syllabus; proposed for joint review

Background
  • UR E26 (ship) and UR E27 (on-board systems and equipment) apply to ships contracted for construction on or after 1 July 2024
  • The requirements mainly concern ship system integration and equipment type approval, not ECDIS operation itself
  • KJ Engineering review: not directly related to JRC ECDIS type-specific training
Option A
Not included. The syllabus stays limited to JRC ECDIS type-specific content.
Option B
Separate optional module on EDUROS. A short general awareness course, outside the 840-min syllabus and the TST certificate.
Option C
Add later if needed. Only if JRC confirms operator-level security procedures in the JAN-9301 manual.

The 840-min, 13-stage syllabus is not affected by this review.
